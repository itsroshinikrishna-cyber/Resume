Glance Pills Studio

Make many cards at once. Add your images, paste or upload the copy (from a spreadsheet or an Excel file), check the matches, then create all the cards. Each one opens in the Studio editor so you can fine-tune it. Put the whole line in the headline cell (for example Find matcha mask for your skin) and the tool sets the hierarchy: small line above, big headline, small line below.

1. Images

Drop your images here, or click to choose (as many as you like)

2. Copy

Columns on each line: kicker | headline | subline, or headline | subline, or just headline. With a header row you can also use image, segment, category, align, format, treatment and gradient (1, 2 or 3) to set things per card. Type \n inside a cell for a line break.

3. Settings for every card (a column in your sheet overrides these)

Order: the 1st image goes with the 1st line, and so on. File name: put the image's file name in an image column. Each image's gradient is picked from the image itself; you can change it per card below.

4. Check the matches

Add images and copy to see your cards here.
